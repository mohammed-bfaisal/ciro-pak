# Video Shotlist

## 3 To 5 Minute Solution Video

- App launch on web or APK.
- City selector and Settings backend status.
- Simulation start.
- Operations rail or mobile dock.
- Manual dispatch.
- Moving unit on route.
- Map overlays.
- AI Dispatch.
- Trace and impact review.
- Crisis messages/actions.
- Backend fallback explanation.

## 2 To 3 Minute Development Usage Video

Show the development workflow without naming private credentials:

- The implementation plan and current source tree.
- Atomic branch/PR workflow on GitHub.
- Local tests/build/lint output.
- Backend test output.
- APK build or sync command.
- Final evidence checklist.

## Capture Quality

- Use 1080p or higher.
- Keep cursor/taps visible.
- Avoid showing provider keys, terminal environment values, private tokens, or unrelated local files.
- Narrate exact feature names from the README and compliance doc.
