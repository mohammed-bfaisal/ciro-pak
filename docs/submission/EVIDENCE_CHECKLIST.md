# Evidence Checklist

## Links To Submit

- Mobile APK download link.
- GitHub repository link.
- 3 to 5 minute solution demo video.
- 2 to 3 minute development usage video.
- README and documentation link.
- Compressed implementation trace/logs package.

## Repository Evidence

- `README.md`
- `docs/submission/REQUIREMENTS_COMPLIANCE.md`
- `docs/submission/APK_CHECKLIST.md`
- `docs/submission/CLOUD_RUN_SETUP.md`
- `docs/submission/DEMO_SCRIPT.md`
- `docs/submission/VIDEO_SHOTLIST.md`
- `docs/submission/EVIDENCE_CHECKLIST.md`
- `docs/submission/VERIFICATION_RESULTS.md`

## Verification Evidence

Capture command output for:

```bash
npm test
npm run build
npm run lint
cd backend
npm test
```

Capture app evidence:

- Dashboard on desktop.
- Dashboard on narrow mobile/APK.
- Settings backend status.
- Map overlays enabled.
- Manual dispatch route.
- AI dispatch trace.
- Crisis detail actions/messages.
- Before/after impact.

## Do Not Include

- Provider API keys.
- `.env` files with secrets.
- APKs built with localhost-only API URLs.
- Stale generated implementation plans as official submission evidence.
