# Demo Script

Target length: 3 to 5 minutes.

1. Open CIRO on web or Android.
2. Select a city, preferably Karachi for visible flood/traffic/weather scenario.
3. Open Settings and show backend status, live-data toggles, and map-layer toggles.
4. Return to Dashboard and start `Simulate`.
5. Show incidents and signals appearing.
6. Open the operations rail or mobile dock.
7. Switch to Manual, select a unit, and dispatch it to an incident marker.
8. Point out the drawn route, moving unit, ETA, provider badge, and route refresh detail.
9. Toggle map overlays: signal heatmap, crisis radius, traffic layer, resource coverage.
10. Press `AI Dispatch`.
11. Show trace events: observation, inference, decision, and execution.
12. Open a crisis detail panel and show actions/messages/impact.
13. Open Settings, disable backend preference, and explain fallback operation.
14. Close by stating that provider secrets live only in the backend environment.

## What To Emphasize

- Agency: the operator can choose manual or AI-assisted dispatch.
- Innovation: map-first emergency operations with traceable reasoning and impact feedback.
- Resilience: the same APK works with live backend data or deterministic fallback data.
- Mobile quality: controls are reachable by touch and the app is not a desktop-only prototype.
